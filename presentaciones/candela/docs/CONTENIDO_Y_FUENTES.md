# Contenido y fuentes

La presentación conserva el orden lógico del PPT EA1 de 25 diapositivas: empresa/producto/destino, alcance, aflatoxinas, requisitos, ISO A, proceso, escenario, no conformidad, ISO B, Ishikawa, cinco porqués, posible causa raíz, prevención y HACCP, proveedor, ISO C, acciones, ISO D, síntesis y conclusión, fuentes.

El caso analiza el bloqueo antes de exportar y la propuesta de control de liberación. Las fuentes externas se identifican como R1–R13 en la presentación.

Fuentes externas identificadas R1–R13 en src/domain.js y en el capítulo Fuentes. La consulta del perfil comercial confirma empresa, producto y Alemania entre destinos, sin acreditar un envío concreto. La tabla de UE 2023/915 para categoría 1.1.11 respalda B1 5 y suma 10 µg/kg; no se usan valores 8/15 de selección o tratamiento posterior. No se realizó auditoría ni revisión normativa integral para una operación real.

Se utiliza ISO 9001:2015 por la consigna académica. La aplicación a las cláusulas es una propuesta del grupo y no acredita certificación ni conformidad integral de Candela.

Sin datos históricos, no se crea un Pareto ni una serie estadística. La evaluación del proveedor y la barrera permiten explorar reglas de decisión. El indicador conserva una presentación estática compacta.

## Integración ISO revisada

Se relee el PDF original Normativa Internacional ISO 9001.2015.pdf, páginas físicas 13–17, 22 y 25–32. Se utilizan paráfrasis, no reproducción de la norma. El bloque A–D se reúne al final: matriz, desarrollo A, B, C y D, conclusiones. Cada cláusula enlaza etapas del flujo ya construido, aplicación, requisitos alimentarios y evidencia. Los vínculos no atribuyen a ISO los límites legales ni a la legislación una firma interna universal de Calidad.
