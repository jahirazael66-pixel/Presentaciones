# Estándar visual del usuario — versión de trabajo

Este documento recoge preferencias expresas del usuario. Todavía no constituye una plantilla universal aprobada; Greenbox sirve como ensayo para refinarla.

## Principios
- Conservar navegación interactiva por secciones, logo integrado e índice, repetición, control de animaciones y pantalla completa.
- Cada presentación debe tener una identidad propia. Elegir una o dos familias tipográficas por presentación, variándolas entre proyectos; combinar claridad y elegancia con una jerarquía visible de tamaños.
- Construir ideas visualmente: diagramas, gráficos, ilustraciones y texto integrado. Evitar exposiciones compuestas únicamente por párrafos o una sucesión uniforme de tarjetas.
- Mantener contexto durante el avance. Las transiciones pueden mover, conectar y transformar elementos compartidos.
- Reservar interacción para navegación y visualizaciones explicativas. El contenido esencial aparece en pantalla sin globos ni ventanas emergentes.
- Texto suficiente para entender el contenido, con pausas y sin saturar. Usar títulos directos, términos explícitos y lenguaje simple.
- Centrar cuando corresponda y equilibrar márgenes; evitar huecos laterales causados por relleno desigual.
- Respetar colores del logo y complementar con blancos, cremas y pasteles cuando encajen con el branding.
- No inventar datos. Distinguir documentación, declaraciones e inferencias. No representar gráficos con precisión temporal o numérica inexistente.

## Aplicación a Greenbox
Se conservan los quince temas: portada, empresa, productos, cadena de valor, agricultores, trabajadores, ambiente, ODS, certificaciones, ISO, clasificación de stakeholders, Matriz de Valor, relaciones, conclusiones y fuentes. El énfasis visual recae en responsabilidad social, certificaciones y stakeholders.

DM Sans resuelve lectura y controles; DM Serif Display aporta contraste editorial. Las ilustraciones SVG son conceptuales, no fotografías ni representación de instalaciones verificadas. GSAP coordina secuencias controladas por el avance; Reveal.js mantiene navegación y transforma elementos identificados entre red y matriz.

## Encargo mínimo para futuras presentaciones
Tema y objetivo; público; duración; información con fuentes; logo e imágenes disponibles; idea visual y restricciones; carpeta de destino; permiso de publicación. Mantener las demás presentaciones.

## Antes de declarar entrega
Revisar cada estado, contraste, alineación, textos, fuentes, teclado, índice, navegación inversa, repetición, movimiento reducido, elección persistente, formato móvil y archivos públicos. Publicar solo dentro del alcance autorizado.
